# AGENTS.md

Working notes for AI agents. The domain overview, `/trigger` parameters, the
configuration reference and the OPUS/SD manager-resolution rules are in
[README.md](README.md) — read it before changing report logic.

## Running tests

**Never run `pytest` on the host.** Always go through the dev stack:

```bash
docker compose run --rm safetynet pytest -m 'not integration_test'   # unit
docker compose run --rm safetynet pytest -m 'integration_test'       # integration
docker compose run --rm safetynet pytest --cov=safetynet --cov-report=term-missing
```

Integration tests need a running OS2mo stack, which provides the external
`os2mo_default` network plus the `msg-broker` and `mox-db` that the FastRAMQPI
fixtures require (they need a broker and a database even though this app is
stateless):

```bash
git clone https://github.com/OS2mo/os2mo.git && cd os2mo
docker compose up -d --build   # MO at localhost:5000
```

The `dipex` client secret it provisions matches `FASTRAMQPI__CLIENT_SECRET` in
`docker-compose.yml`.

## Integration test invariants

- **Every test starts against an empty MO.** The auto-applied
  `os2mo_database_isolation` fixture resets the database to migrated-but-empty
  before each test. Never look anything up from MOs own fixture data. Seed via
  the `_testing__*` operations in `queries.graphql`: `root_org` first, then
  `class_uuids` (driven by `MO_CLASSES`), then the org tree.
- The reset truncates the **shared** MO database, so a test run destroys
  whatever a dev stack had loaded.
- Prefer integration tests over unit tests, and avoid mocks.
- The suite covers 100% of `safetynet/`, statements and branches — keep it
  there. `[tool.coverage.run]` omits the generated client. CI's
  `PYTEST_COV_FAIL_UNDER` is 0 only because its two jobs each measure a subset.

## GraphQL client

- `safetynet/autogenerated_graphql_client/` is generated. Never hand-edit it.
  Regenerate with `ariadne-codegen client` (in the `dev` poetry group) after
  changing `queries.graphql` or `schema.graphql`.
- Regeneration does **not** delete the files of operations you removed — delete
  those by hand.
- Bumping the MO GraphQL version: update `GRAPHQL_VERSION` in
  `safetynet/main.py`, re-fetch the schema
  (`curl -O http://localhost:5000/graphql/v30/schema.graphql`), then regenerate.
- The `ShorterResultsPlugin` unwraps single-top-field queries, so a response is
  that field's value rather than a wrapper object.

## Gotchas

- Changing `pyproject.toml` requires `docker compose build safetynet` before the
  new config takes effect: only `safetynet/` and `tests/` are bind-mounted.

## Conventions

- Use `one`, `only` or `first` from `more_itertools` instead of `[0]`.
- Conventional Commits with a ticket number, e.g.
  `feat: [#69034] trigger reports over HTTP`.
- Every file needs SPDX headers (`MPL-2.0`, `Magenta ApS`); blanket annotations
  for generated/lock/doc files live in `REUSE.toml`.
- `pre-commit run --all-files` must pass before committing.
- Avoid em-dashes in comments and commit messages.
